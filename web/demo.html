Как это устроено
  • Snag написан на Go. Для демо тот же код приёма, группировки и API собран в WebAssembly и работает в этой вкладке.
  • SDK Sentry отправляет ошибки не по сети, а прямо в Snag внутри страницы. На сервере это обычный HTTP.
  • На настоящем сервере события лежат в ClickHouse, проблемы — в Postgres. Здесь всё в памяти вкладки и пропадёт при перезагрузке.
  • В истории уже есть ошибки выдуманного магазина за две недели, чтобы было что посмотреть.
